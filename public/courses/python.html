Chapitre 01 · Pourquoi Python

Python — le langage qui a révolutionné la data

Python n'est pas le seul langage pour la data. Mais c'est le plus utilisé, le plus enseigné et celui qui a le meilleur écosystème. Voici pourquoi, et ce que vous pouvez faire avec.

Qu'est-ce que Python ?

Python est un langage de programmation interprété, créé en 1991 par Guido van Rossum. Son nom vient des Monty Python — le groupe comique britannique. Sa philosophie : le code doit être lisible, explicite et élégant.

Le Zen de Python

Beautiful is better than ugly. Explicit is better than implicit. Simple is better than complex. Readability counts. — Tim Peters (PEP 20)

Python est un langage interprété (pas besoin de compiler), dynamiquement typé (pas besoin de déclarer le type des variables), et multi-paradigme (impératif, fonctionnel, orienté objet).

Pourquoi Python a écrasé la concurrence en data
vs R
Plus polyvalent
R est excellent pour les statistiques pures mais limité hors data science. Python couvre la data science, le web, l'automation, le scripting — un seul langage pour tout faire.
vs SAS/SPSS
Gratuit et open source
SAS coûte des milliers d'euros par an. Python est 100% gratuit. L'écosystème open source a produit des librairies souvent supérieures aux outils propriétaires.
vs Excel
Automatisable et scalable
Excel est limité à 1M lignes et ne s'automatise pas facilement. Python traite des milliards de lignes, tourne la nuit sans intervention, s'intègre dans des pipelines.

Variables et types de données

En Python, vous n'avez pas besoin de déclarer le type — Python le déduit automatiquement. Les 4 types fondamentaux :

TYPE 01
int & float
Nombres entiers et décimaux. Opérations arithmétiques standards + ** pour la puissance.
age = 28 · salaire = 450000.0
TYPE 02
str (chaîne)
Texte entre guillemets simples ou doubles. Méthodes : .upper(), .split(), .strip(), f-strings.
nom = "Adjoa" · f"Bonjour {nom}"
TYPE 03
bool
True ou False. Résultat de comparaisons. Base des conditions if/elif/else.
actif = True · score > 70
TYPE 04
list
Collection ordonnée et modifiable. Indexée depuis 0. Méthodes : .append(), .sort(), slicing.
notes = [14, 18, 12, 16, 20]
TYPE 05
dict
Paires clé-valeur. La structure de données la plus utilisée en data. Accès par clé.
client = {{"nom":"Ali", "ca":84000}}
TYPE 06
None
Valeur nulle — équivalent de NULL en SQL. Résultat par défaut d'une fonction sans return.
valeur = None · if x is None:

Fonctions Python
Python
# Définition d'une fonction avec paramètres et valeur par défaut
def analyser_performance(ca_actuel, ca_objectif, taux_commission=0.05):
    """
    Analyse la performance commerciale d'un agent.
    Retourne un dictionnaire avec les métriques clés.
    """
    taux_atteinte = ca_actuel / ca_objectif * 100
    commission = ca_actuel * taux_commission if taux_atteinte >= 80 else 0
    statut = "Objectif atteint" if taux_atteinte >= 100 else "En cours"

    return {{
        "taux_atteinte": round(taux_atteinte, 1),
        "commission": commission,
        "statut": statut
    }}

# Utilisation
result = analyser_performance(1_650_000, 1_500_000)
print(result)
# {'taux_atteinte': 110.0, 'commission': 82500.0, 'statut': 'Objectif atteint'}

Chapitre 04 · NumPy & Pandas

NumPy & Pandas — manipuler des données réelles

NumPy est la fondation du calcul numérique en Python. Pandas est la librairie de référence pour l'analyse de données tabulaires. Ensemble, ils remplacent Excel pour tous vos besoins data.

NumPy — Arrays et calcul vectorisé
Python
import numpy as np

# Créer un array NumPy
ventes = np.array([84000, 92000, 78000, 105000, 88000])

# Opérations vectorisées (sur tout le tableau d'un coup)
print(ventes * 1.1)          # Augmenter toutes les ventes de 10%
print(np.mean(ventes))       # Moyenne : 89400.0
print(np.std(ventes))        # Écart-type
print(np.percentile(ventes, [25, 50, 75]))  # Quartiles

# Filtrage booléen (sans boucle)
au_dessus_moy = ventes[ventes > np.mean(ventes)]
print(f"Au-dessus de la moyenne : {au_dessus_moy}")

Chapitre 06 · Analyse exploratoire

EDA — analyser un dataset de A à Z

L'EDA (Exploratory Data Analysis) est la première étape de tout projet data. Elle vous permet de comprendre la structure, la qualité et les patterns de vos données avant toute modélisation.

Les 6 étapes d'une EDA rigoureuse
ÉTAPE 01
Structure des données
Shape, types, aperçu. Combien de lignes ? Quels types de colonnes ? Y a-t-il des doublons ?
df.shape · df.dtypes · df.head()
ÉTAPE 02
Qualité des données
Valeurs manquantes, valeurs aberrantes (outliers), valeurs impossibles.
df.isnull().sum() · df.duplicated()
ÉTAPE 03
Statistiques descriptives
Distribution des variables numériques : min, max, moyenne, médiane, écart-type, quartiles.
df.describe() · skewness
ÉTAPE 04
Distribution univariée
Histogrammes et box plots pour chaque variable. Identifier les distributions asymétriques.
sns.histplot() · sns.boxplot()
ÉTAPE 05
Corrélations
Matrice de corrélation, scatter plots. Quelles variables sont liées entre elles ?
df.corr() · sns.heatmap()
ÉTAPE 06
Segmentation & patterns
GroupBy, pivot tables, analyse par segment. Quels groupes se distinguent ?
df.groupby().agg() · pd.crosstab()
